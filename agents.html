Choose a tool by intent

check_page — browser QA and screenshots
Use for broad responsive-layout, accessibility, console, network, and performance evidence across phone portrait, phone landscape, and desktop.
verify_page — website assertions
Use when an agent has explicit pass/fail assertions such as visible text, a title, a selector, horizontal overflow, or console errors. Includes the full browser QA pass.
compare_page — visual regression testing
Use after a baseline check to compare screenshots, accessibility issues, errors, and performance evidence.
extract_page — webpage to Markdown
Use to turn one public HTML page into deterministic clean Markdown without browser execution.
web_release_gate — passive website security review
Use to review security headers, cookie flags, mixed content, cross-origin script integrity, and server disclosure without probing.
get_report — free report retrieval
Use to poll a submitted job and retrieve its completed structured evidence.
