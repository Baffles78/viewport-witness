# ViewportWitness

ViewportWitness is a machine-facing browser QA API. It checks one public HTTPS page at phone portrait, phone landscape, and desktop sizes, then returns a structured report and screenshots.

The first build runs locally in clearly labeled test mode. The x402 payment path is prepared for an exact $0.08 USDC payment on Base, but mainnet activation and public deployment are deliberately separate reviewed steps.

See [the build specification](docs/BUILD-SPEC.md). Setup and operating instructions will be added by the implementation build.
